# TradingRuleSystem2026 — 个人交易记录与纪律约束系统 V1

单文件、零依赖、纯前端。数据只存在本浏览器 `localStorage`（key：`tradingRuleSystem2026_v1`），不上传服务器，无登录。

## 功能（V1）

- 多账户管理：每个账户填账户净值，用于仓位反推（单笔极端止损 ≤ 净值 2%~5%）
- 手动录入：正股买入/做空；期权卖出 Put、牛市看跌价差、卖出 Call、买入 Call/Put，含代码、成交价、行权价、行权日、Delta
- 录入三步向导：第 2 步强制过“灵魂三问”（黑天鹅 -15% 止损价与可接受亏损 / 接盘意愿与砍价 / 最长等待天数），默认值按笔记自动算，可改
- 机械化止盈止损：第 3 步自动算出并随记录保存
  - 卖方期权：止盈买回价 = 权利金 × 0.40（赚 60%，在 50%~70% 区间）；止损买回价 = 权利金 × 2.5（在 2~3 倍区间），或跌破行权价直接认赔
  - 价差：最大亏损 =（卖出行权价 − 买入行权价）×100×张数 − 净权利金
  - 接盘后硬止损：杠杆 ETF 成本下 8%~10%，普通正股 10%~15%；时间止损 3~5 天（默认 5 天）
  - 正股：笔记未给固定止盈口径，默认不设机械止盈，以硬止损 + 时间止损离场
  - 买入期权：V1 约定口径，止盈 2 倍权利金、止损亏 50%，可在第 3 步前通过数值理解，不可直接在界面改——如需改口径请在代码 `calcPlan` 中调整
- 平仓：填平仓价/到期归零/被行权，自动算盈亏；不提供展期，展期请先平仓再新开一笔
- Q1 双向联动：止损价与预估亏损改一边另一边马上重算（正股按成交价差×股数，卖方期权按内在价值口径，价差封顶于最大亏损）
- 正股止盈：笔记无固定口径，由用户在第 1 步或第 3 步手动填目标价，留空=不设固定止盈
- 展示：缩略模式用表格对齐只显止盈/止损/止损时间/三问；点“详情”在当前记录下展开完整表格，内有“关闭详情”按钮，不再弹窗
- 列表：当前账户的持仓在上，已平仓在下方折叠区；每笔可手动删除
- 备份：导出 / 导入 JSON；localStorage 只在本设备本浏览器有效，请定期导出
